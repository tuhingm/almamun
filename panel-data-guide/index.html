Python · Static panel

Pooled OLS, RE, FE, FD and Mundlak

Runs the wagepan and crime4 empirical exercises. Reports the union coefficient and entity-clustered standard errors, performs a joint Mundlak test, and compares deterrence elasticities under pooled OLS and two-way FE.

  • Packages: wooldridge, pandas, statsmodels, linearmodels.
  • Data are loaded from the Wooldridge dataset package.
View installation and execution
python -m pip install wooldridge pandas statsmodels linearmodels
python panel_static_models.py

from linearmodels.panel import PanelOLS, RandomEffects
import wooldridge as wd
panel = wd.data("wagepan").set_index(["nr", "year"])
fe = PanelOLS.from_formula(
    "lwage ~ union + married + expersq + TimeEffects + EntityEffects",
    data=panel
).fit(cov_type="clustered", cluster_entity=True)
re = RandomEffects.from_formula(
    "lwage ~ 1 + union + married + expersq", data=panel
).fit(cov_type="clustered", cluster_entity=True)
print(fe.summary)
print(re.summary)

Reproducibility note. The two Python scripts follow the datasets and coding exercises in Lectures 7 and 8. The Stata files are reusable workflows requiring the researcher to map their own variable names and verify the relevant assumptions. The macro-panel do-file calls community-contributed Stata commands; package installation and command availability depend on the installed Stata version.
How the tool decides. Panels with a median of fewer than 15 periods per unit are treated as short (micro) panels: the F test asks whether unit effects matter, the Breusch–Pagan LM test whether random effects improve on pooled OLS, and the cluster-robust Mundlak test (reported with the conventional Hausman test) whether the unit effects are correlated with the regressors. Longer panels are treated as macro panels: the Pesaran CD test checks for cross-sectional dependence, the Pesaran–Yamagata Δ test for slope heterogeneity, and each variable is tested for a unit root in levels and differences with CIPS when it is cross-sectionally dependent and with the Fisher-ADF (Choi Z) test otherwise. CIPS p-values come from simulated critical values. When every variable is I(1), cointegration is tested with the Fisher–Engle–Granger test if slopes are heterogeneous and with the Kao test otherwise. These are standard rules, but panel tests have low power when T is short and can be distorted by breaks, so treat the result as a starting point and justify the choice in your paper.
