How the tool decides. Panels with a median of fewer than #LONGT# periods per unit are treated as short (micro) panels: the F test asks whether unit effects matter, the Breusch–Pagan LM test whether random effects improve on pooled OLS, and the cluster-robust Mundlak test (reported with the conventional Hausman test) whether the unit effects are correlated with the regressors. Longer panels are treated as macro panels: the Pesaran CD test checks for cross-sectional dependence, the Pesaran–Yamagata Δ test for slope heterogeneity, and each variable is tested for a unit root in levels and differences with CIPS when it is cross-sectionally dependent and with the Fisher-ADF (Choi Z) test otherwise. CIPS p-values come from simulated critical values. When every variable is I(1), cointegration is tested with the Fisher–Engle–Granger test if slopes are heterogeneous and with the Kao test otherwise. These are standard rules, but panel tests have low power when T is short and can be distorted by breaks, so treat the result as a starting point and justify the choice in your paper.
