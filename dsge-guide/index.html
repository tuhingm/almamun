DSGE Research Guide

A practical workflow for developing, solving, estimating and evaluating empirical Dynamic Stochastic General Equilibrium models. All computational examples and implementation workflows in this guide use Dynare.

Dynare only computational environmentModel development · Bayesian estimation · Policy analysis

This is a research-oriented companion to the DSGE material in Monetary Economics. The monetary-economics lectures develop economic theory; this guide focuses on turning a structural model into a transparent, reproducible empirical paper using Dynare and its native model, estimation and reporting commands.

Scope

What this guide covers

  • Steady states, model diagnostics and solution.
  • Calibration and Bayesian estimation.
  • Impulse responses and shock decompositions.
  • Model comparison, sensitivity and policy experiments.
  • Replication-ready Dynare project organization.

Research workflow

From economic question to empirical DSGE paper

Follow the sequence; do not begin Bayesian estimation before the model's equilibrium and solution properties are checked.

01 · Research question

Define the policy or macroeconomic mechanism, target variables, sample and empirical contribution.

02 · Model structure

Specify agents, optimization problems, constraints, market clearing and exogenous shock processes.

03 · Equilibrium system

Derive first-order conditions and express the model as a coherent nonlinear system.

04 · Steady state

Derive analytical steady-state relationships where possible; implement and verify them in Dynare.

05 · Solution diagnostics

Run model checks, inspect eigenvalues and verify the Blanchard–Kahn conditions.

06 · Calibration

Document parameter sources, units, targets and the distinction between calibrated and estimated parameters.

07 · Bayesian estimation

Define observables, measurement equations, priors, likelihood settings and MCMC configuration.

08 · Empirical results

Report posterior estimates, credible intervals, convergence diagnostics, IRFs and shock decompositions.

09 · Evaluation

Assess fit, compare specifications, test prior and parameter sensitivity, and report limitations.

Dynare model implementation

Baseline New Keynesian model file

A compact illustrative three-equation model. It is a teaching template, not a calibrated or estimated empirical specification.

1. Declare variables and parameters

var y pi i;
varexo e_r e_g;
parameters beta sigma kappa rho_i phi_pi phi_y;

beta   = 0.99;
sigma  = 1.00;
kappa  = 0.10;
rho_i  = 0.80;
phi_pi = 1.50;
phi_y  = 0.125;

2. Specify equilibrium conditions and shocks

model;
  y = y(+1) - (1/sigma)*(i-pi(+1)) + e_g;
  pi = beta*pi(+1) + kappa*y;
  i = rho_i*i(-1) + (1-rho_i)*(phi_pi*pi+phi_y*y) + e_r;
end;

shocks;
  var e_r; stderr 0.0025;
  var e_g; stderr 0.0100;
end;

3. Solve and generate model moments

steady;
check;
model_diagnostics;
stoch_simul(order=1, irf=20) y pi i;
The template uses zero steady states for the log-deviation variables and illustrative parameter values. A paper-specific model must derive its own steady state, measurement system, shock processes and parameterization.
Bayesian estimation

Dynare estimation block

For empirical estimation, add observed data series and measurement equations that map model variables into the units and transformations of the dataset.

Illustrative estimation syntax

varobs y_obs pi_obs i_obs;

estimated_params;
  sigma,     1.00, 0.10, 5.00, gamma_pdf, 1.00, 0.25;
  kappa,     0.10, 0.01, 1.00, beta_pdf,  0.10, 0.05;
  rho_i,     0.80, 0.01, 0.99, beta_pdf, 0.80, 0.10;
  phi_pi,    1.50, 1.01, 4.00, normal_pdf, 1.50, 0.25;
  phi_y,     0.125,0.00, 1.00, normal_pdf, 0.125,0.05;
  stderr e_r, 0.0025, 0.0001, 0.05, inv_gamma_pdf, 0.0025, 0.001;
  stderr e_g, 0.0100, 0.0001, 0.10, inv_gamma_pdf, 0.0100, 0.005;
end_params;

estimation(
  datafile=macro_data,
  first_obs=1,
  nobs=200,
  mode_compute=6,
  mh_replic=20000,
  mh_nblocks=2,
  mh_jscale=0.30,
  bayesian_irf
);
This block is a syntax scaffold, not a ready-to-run estimation file: define the observable variables and measurement equations, ensure all estimated parameters enter the model, and verify prior support and data transformations. Set sample options to match the actual dataset.
Results and reporting

Required empirical outputs

Estimation and diagnostics

  • Prior and posterior parameter distributions.
  • Posterior mode and marginal likelihood.
  • MCMC trace plots, acceptance rates and convergence checks.
  • Steady-state and solution diagnostics.
  • Data transformations and measurement equations.

Structural interpretation

  • Impulse responses with uncertainty bands.
  • Forecast error variance decomposition.
  • Historical shock decomposition.
  • Smoothed shocks and state estimates.
  • Counterfactual policy simulations.

Dynare commands to learn

var, varexo, parameters, model, steady, steady_state_model, check, model_diagnostics, stoch_simul, estimated_params, estimation, shock_decomposition, forecast.

Paper organization

  1. Research question and contribution.
  2. Model environment and derivation.
  3. Calibration and data.
  4. Estimation strategy and priors.
  5. Baseline results and diagnostics.
  6. Robustness and policy counterfactuals.
Replication standard

Recommended project structure

dsge-project/
  main_model.mod
  steady_state.mod
  measurement_equations.mod
  estimation.mod
  macro_data.xlsx
  README.md
  output/
    posterior/
    irfs/
    shock_decomposition/
    tables/
    figures/

Keep the submitted replication package self-contained. Record the Dynare version, data source, sample dates, transformations, random seeds where applicable, estimation settings and all model-file dependencies.

Research standard: A DSGE paper should make the mapping from economic theory to the solved model, observed data, likelihood and reported policy conclusions fully auditable. Dynare code should reproduce every reported table and figure.
