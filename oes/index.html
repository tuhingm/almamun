05 / METHODOLOGY ROADMAP

Econometric methods

The platform is being developed as a modular econometric system. The categories below describe the planned scope; they are not all available for estimation in this release.

Available in this release

Ordinary least squares: coefficient estimation, conventional covariance and HC0–HC3 robust covariance estimators, confidence intervals, residuals, fitted values and model fit statistics.

Time-series econometrics
ARDL, VAR/VECM, unit-root and cointegration procedures, volatility models and forecasting.
Panel-data econometrics
Fixed and random effects, pooled models, dynamic panels, PMG/MG/DFE and cross-sectionally augmented models.
Causal inference
Difference-in-Differences, event studies, synthetic control, matching and treatment-effect estimation.
Bayesian and machine learning
Bayesian regression, state-space models, regularization, tree-based methods and model evaluation.
06 / PLATFORM INFORMATION

Open and reproducible research

Open Econometric Systems is designed as a free, browser-accessible econometric platform. The website provides the user interface; numerical estimation is performed by a separate Python API service. Dataset processing and estimation are initiated only when the user submits a model.

Development status: the OES interface is being integrated into this website. The estimation API must be deployed and its URL entered above before live estimation is available. The methods roadmap should not be interpreted as a list of currently implemented estimators.
