4. Select cleaning operations

Safe operations are selected by default. Substantive changes are opt-in and clearly recorded.

Smart missing-value filling

Choose a filling method separately for each variable. Recommendations use detected variable types. No values are imputed until you select a method.

Upload a dataset to configure filling.
Filling methods are explicit and variable-specific. Forward/backward fill and linear interpolation follow current row order, within selected entity groups when an identifier is supplied. Linear interpolation fills only interior gaps. Duplicate entity-time keys are reported, not automatically deleted.
