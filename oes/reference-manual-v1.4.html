Abstract

This reference manual documents Open Econometric Systems (OES), an open-source, browser-based platform for econometric and statistical analysis. Version 1.4 brings together 69 models organized into six methodological groups: Time Series, Panel Data, Causal Inference, Machine Learning, Bayesian Econometrics, and Markov Switching. The platform provides an in-browser computational environment built around Python and Pyodide, enabling users to work with datasets and execute supported estimation procedures in their web browsers. The manual describes the platform's model coverage, computational environment, and procedures for using OES.
