Exploratory factor analysis (EFA)

Exploratory factor analysis models the correlations among observed variables by a smaller number of latent common factors, estimated by maximum likelihood, and rotates the solution for interpretation.

Overview

Exploratory factor analysis models the correlations among observed variables by a smaller number of latent common factors, estimated by maximum likelihood, and rotates the solution for interpretation.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

x = Λ f + ε, Var(f) = I (orthogonal) or Φ, Var(ε) = Ψ diagonal; Σ = ΛΛ' + Ψ.
ML discrepancy: F(Λ, Ψ) = log|Σ| + tr(Σ⁻¹ R) − log|R| − p, minimised with respect to Ψ (Λ concentrated out by an eigen-decomposition of Ψ^{-1/2} R Ψ^{-1/2}).
Likelihood-ratio test of exact fit: χ² = (n − 1 − (2p + 5)/6 − 2m/3) F̂ with df = [(p − m)² − (p + m)]/2.
Rotations: varimax (orthogonal), promax (oblique, power 4 from the varimax solution), oblimin by gradient projection.

Assumptions

  • Continuous (approximately multivariate normal) data for the ML estimates and the χ² test.
  • The number of factors is chosen beforehand; df ≥ 0 so the model is identified.
  • Large enough sample (a common minimum is 5–10 observations per variable).

Estimation algorithm

  • L-BFGS-B on the uniquenesses with bounds [0.005, 1] and analytic gradient; Heywood cases (uniqueness at the lower bound) are flagged; rotation by iterative algorithms; Kaiser-Meyer-Olkin, Bartlett sphericity and parallel analysis as diagnostics.

Diagnostics and interpretation

  • Loadings show how strongly a variable reflects a factor; communality is the share of its variance explained by the common factors; the χ² test of exact fit is very demanding, so consult RMSEA as well.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • Heywood cases (uniqueness near 0) occur in small samples.
  • Rotated solutions are unique only up to the rotation criterion chosen.
  • Ordinal items would call for polychoric correlations, which are not implemented: Pearson correlations are used.

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/bfi_items.csv').read()
spec = {
    "vars": [
        "N1",
        "N2",
        "N3",
        "N4",
        "N5",
        "E1",
        "E2",
        "E3",
        "E4",
        "E5"
    ],
    "n_factors": 2,
    "rotation": "varimax"
}
result = o.run('stat_efa', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
