Principal component analysis (PCA): technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

Principal component analysis finds orthogonal linear combinations of the variables that successively capture the largest variance, for dimension reduction and description.

2.Historical and theoretical background

Pearson (1901) and Hotelling (1933).

3.Mathematical formulation

Standardise to correlation form (or centre for covariance form): Z; S = Z'Z/(n − 1).
Eigendecomposition S = V Λ V'; component scores = Z V; loadings = V Λ^{1/2} (correlations of variables with components for the correlation basis).
Variance explained by component j: λ_j / Σ λ.
Retention guides: Kaiser (λ > 1), broken-stick, and Horn's parallel analysis (95th percentile of eigenvalues of random normal data, simulated with the supplied seed).

4.Statistical assumptions

  • Continuous variables measured on comparable scales or standardised.
  • Linear structure; no distributional assumption for the descriptive use.

5.Estimation algorithm

  • Symmetric eigendecomposition (numpy eigh); sign convention making the largest absolute loading positive; Bartlett's sphericity and KMO as suitability checks.

6.Computational implementation

  • Module oes/engine/oes_engine/stat_multivariate.py, function pca, registered as stat_pca in stat_registry.py.
  • Runtime dependencies: NumPy, pandas and SciPy only (the packages available in the browser Pyodide runtime); no backend.
  • Input validation: missing columns, empty data, non-numeric or constant variables, wrong number of groups, singular matrices and non-convergence return a plain-language error instead of an exception (tests in stat-validation/tests/test_stat_division.py).
  • Example run time: 0.02 s in CPython; real browser (Pyodide) timing has not been measured.

12.Diagnostics and interpretation

  • Loadings above about 0.4 in absolute value mark the variables that define a component; the scree plot and parallel analysis guide the number to keep.

13.Computational limitations

  • PCA is sensitive to outliers and to the choice of covariance or correlation basis.
  • Principal components are not latent factors: use factor analysis for a measurement model.

import sys; sys.path.insert(0, 'oes/engine')

spec = {
    "vars": [
        "Murder",
        "Assault",
        "UrbanPop",
        "Rape"
    ]
}
result = o.run('stat_pca', csv, spec)
for t in result['tables']:
