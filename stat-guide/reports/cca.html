Canonical correlation analysis (CCA): technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

Canonical correlation analysis finds paired linear combinations of two sets of variables with maximal correlation.

2.Historical and theoretical background

Hotelling (1936).

3.Mathematical formulation

With within-set covariance matrices S_xx, S_yy and cross-covariance S_xy, the squared canonical correlations ρ_k² are the eigenvalues of S_xx⁻¹ S_xy S_yy⁻¹ S_yx.
Sequential Wilks' Λ_k = Π_{j ≥ k} (1 − ρ_j²); Bartlett χ² = −[n − 1 − (p + q + 1)/2] log Λ_k with df = (p − k + 1)(q − k + 1); Rao's F approximation as an alternative.
Optional permutation test of the first canonical correlation (rows of one set permuted), with the Phipson-Smyth p-value.

4.Statistical assumptions

  • Linear relations between the sets; multivariate normality for the Bartlett and Rao tests (the permutation test does not need it).
  • More observations than the total number of variables.

5.Estimation algorithm

  • Whitening of both sets followed by an SVD of the cross-covariance; standardised coefficients, structure correlations and redundancy indices.

6.Computational implementation

  • Module oes/engine/oes_engine/stat_multivariate.py, function cca, registered as stat_cca in stat_registry.py.
  • Runtime dependencies: NumPy, pandas and SciPy only (the packages available in the browser Pyodide runtime); no backend.
  • Input validation: missing columns, empty data, non-numeric or constant variables, wrong number of groups, singular matrices and non-convergence return a plain-language error instead of an exception (tests in stat-validation/tests/test_stat_division.py).
  • Example run time: 0.01 s in CPython; real browser (Pyodide) timing has not been measured.

12.Diagnostics and interpretation

  • The first canonical correlation is the largest correlation attainable between any linear combination of one set and any of the other; test pairs sequentially.

13.Computational limitations

  • Estimates of the first canonical correlation are biased upward in small samples.
  • Canonical weights are unstable under multicollinearity; read the structure correlations.
