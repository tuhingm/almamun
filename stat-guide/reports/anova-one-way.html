One-way ANOVA: technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

One-way analysis of variance compares the means of k independent groups with a single F test and follows a significant result with pairwise comparisons.

2.Historical and theoretical background

Introduced by R. A. Fisher in the 1920s for agricultural experiments; Welch (1951) added a test that does not require equal variances, and Tukey (1949) and Games and Howell (1976) added the pairwise procedures used here.

3.Mathematical formulation

Model: y_ij = μ + α_i + ε_ij, ε_ij ~ N(0, σ²), i = 1..k, j = 1..n_i, Σ n_i α_i = 0.
SS_B = Σ n_i (ȳ_i − ȳ)², SS_W = Σ Σ (y_ij − ȳ_i)², N = Σ n_i.
F = [SS_B / (k − 1)] / [SS_W / (N − k)] ~ F(k − 1, N − k) under H0: α_1 = … = α_k = 0.
Welch: F_W = [Σ w_i (ȳ_i − ȳ_w)² / (k − 1)] / [1 + 2(k − 2)/(k² − 1) Σ (1 − w_i/W)² / (n_i − 1)], w_i = n_i / s_i², with df1 = k − 1 and df2 = (k² − 1) / [3 Σ (1 − w_i/W)² / (n_i − 1)].
Effect sizes: η² = SS_B / SS_T, ω² = (SS_B − (k − 1) MS_W) / (SS_T + MS_W); confidence interval for η² by inverting the noncentral F distribution.

4.Statistical assumptions

  • Independent observations within and between groups.
  • Normally distributed errors (the F test is fairly robust with moderate n; see the robustness runs).
  • Equal variances for the classical F test; Welch's test and Games-Howell comparisons do not need this.

5.Estimation algorithm

  • Group means and variances → between and within sums of squares → F and p-value from the central F distribution.
  • Welch ANOVA and Brown-Forsythe/Levene checks are computed alongside; Tukey HSD uses the studentised range distribution, Games-Howell uses Welch degrees of freedom with the studentised range.

6.Computational implementation

  • Module oes/engine/oes_engine/stat_anova.py, function anova1, registered as stat_anova1 in stat_registry.py.
  • Runtime dependencies: NumPy, pandas and SciPy only (the packages available in the browser Pyodide runtime); no backend.
  • Input validation: missing columns, empty data, non-numeric or constant variables, wrong number of groups, singular matrices and non-convergence return a plain-language error instead of an exception (tests in stat-validation/tests/test_stat_division.py).

7.Monte Carlo experimental design

Each replication draws a new data set from a fixed data-generating process and runs the engine exactly as the web page does. Replication r at size n uses numpy.random.default_rng([method_code, scenario_index, n, r]), so any replication can be rerun alone. Failures are counted, never discarded silently. Sizes n are the total number of observations (subjects for repeated-measures designs, studies for meta-analysis). A per-cell time budget of 45.0 s stops very slow cells early; the replications actually run are shown in every results table.

12.Diagnostics and interpretation

  • A small p-value says the group means are not all equal; it does not say which differ: read the pairwise table.
  • η² is the share of total variance associated with the grouping; by convention 0.01, 0.06 and 0.14 are small, medium and large but context matters.
  • If the Welch p-value and the classical p-value disagree, trust Welch when group variances differ.

13.Computational limitations

  • The normality check is a diagnostic, not a guarantee; heavy tails reduce power.
  • Unbalanced designs with unequal variances inflate or deflate the classical F test: use the Welch result then (see robustness results).

Slowest simulated cell: 0.009 s per run (H0, heteroskedastic + unbalanced (robustness), n = 1000), in CPython on a shared two-core machine. Browser speed with Pyodide is expected to be several times slower and was not measured.
