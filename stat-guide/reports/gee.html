Generalised estimating equations (GEE): technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated with a documented deviation Independence/exchangeable match statsmodels; AR(1) with estimated alpha uses a different moment estimator (see limitations); QIC follows Pan (2001) and differs from statsmodels' QIC.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

Generalised estimating equations estimate population-averaged regression effects for clustered or longitudinal data with robust standard errors that remain valid when the working correlation is misspecified.

2.Historical and theoretical background

Liang and Zeger (1986); Pan (2001) gave the QIC for working-correlation selection.

3.Mathematical formulation

Estimating equation: Σ_i D_i' V_i⁻¹ (y_i − μ_i) = 0, V_i = φ A_i^{1/2} R(α) A_i^{1/2}.
Robust (sandwich) covariance: B⁻¹ M B⁻¹ with B = Σ D'V⁻¹D and M = Σ D'V⁻¹ (y − μ)(y − μ)' V⁻¹ D.
Working correlation: independence, exchangeable (α from the moment estimator), AR(1).
QIC = −2Q(β̂) + 2 tr(Ω̂_I V̂_R), as defined by Pan (2001).

4.Statistical assumptions

  • Correct mean model and link; independent clusters.
  • Missing data completely at random (GEE is not valid under MAR without weighting).
  • Enough clusters (about 30 or more) for the sandwich estimator to be reliable.

5.Estimation algorithm

  • Iteratively reweighted fitting with moment estimates of the scale and α; the sandwich estimator; naive SE reported alongside.

6.Computational implementation

  • Module oes/engine/oes_engine/stat_mixed.py, function gee, registered as stat_gee in stat_registry.py.
  • Runtime dependencies: NumPy, pandas and SciPy only (the packages available in the browser Pyodide runtime); no backend.
  • Input validation: missing columns, empty data, non-numeric or constant variables, wrong number of groups, singular matrices and non-convergence return a plain-language error instead of an exception (tests in stat-validation/tests/test_stat_division.py).
  • Example run time: 0.01 s in CPython; real browser (Pyodide) timing has not been measured.

7.Monte Carlo experimental design

Each replication draws a new data set from a fixed data-generating process and runs the engine exactly as the web page does. Replication r at size n uses numpy.random.default_rng([method_code, scenario_index, n, r]), so any replication can be rerun alone. Failures are counted, never discarded silently. Sizes n are the total number of observations (subjects for repeated-measures designs, studies for meta-analysis). A per-cell time budget of 8.0 s stops very slow cells early; the replications actually run are shown in every results table.

13.Computational limitations

  • The AR(1) correlation parameter is estimated by a different moment estimator than the one in statsmodels: with α fixed at the same value the coefficients agree exactly, but with α estimated they can differ (in the binomial benchmark by up to 0.55), so AR(1) results should be read as one valid GEE fit, not as a statsmodels replica.
  • statsmodels' QIC omits a weighting of Pan's trace term; the engine follows Pan's definition, so QIC values differ although QICu agrees exactly.

Slowest simulated cell: 0.040 s per run (Binomial, exchangeable (marginal log-odds attenuated), n = 1000), in CPython on a shared two-core machine. Browser speed with Pyodide is expected to be several times slower and was not measured.
