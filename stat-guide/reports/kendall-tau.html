Kendall's tau correlation: technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

Kendall's tau measures the monotone association of two variables through the numbers of concordant and discordant pairs, with an exact test for small samples and a tie-corrected version (tau-b).

2.Historical and theoretical background

Introduced by Kendall (1938).

3.Mathematical formulation

τ_a = (C − D) / [n(n − 1)/2]; τ_b = (C − D) / sqrt[(n0 − n1)(n0 − n2)], n0 = n(n − 1)/2, n1 = Σ t_i(t_i − 1)/2, n2 = Σ u_j(u_j − 1)/2.
Exact null distribution of D (no ties) by Mahonian numbers (counting permutations by inversions).
Normal approximation: z = (C − D) / sqrt Var, Var = [v0 − vt − vu]/18 + v1 + v2, with the usual tie terms.
Approximate confidence interval for τ_b: tanh(atanh τ_b ± z sqrt(0.437/(n − 4))) (Fieller, Hartley and Pearson 1957); τ_a and τ_c (Stuart) are also reported.

4.Statistical assumptions

  • Independent pairs of observations.
  • Ordinal or continuous measurements.
  • Monotone (not necessarily linear) association.

5.Estimation algorithm

  • Pair counting in O(n²) with vectorised comparison; exact test when there are no ties and n is small; otherwise normal approximation; Spearman's ρ is reported for comparison.

6.Computational implementation

  • Module oes/engine/oes_engine/stat_nonparam.py, function kendall, registered as stat_kendall in stat_registry.py.
  • Runtime dependencies: NumPy, pandas and SciPy only (the packages available in the browser Pyodide runtime); no backend.
  • Input validation: missing columns, empty data, non-numeric or constant variables, wrong number of groups, singular matrices and non-convergence return a plain-language error instead of an exception (tests in stat-validation/tests/test_stat_division.py).
  • Example run time: 0.00 s in CPython; real browser (Pyodide) timing has not been measured.

7.Monte Carlo experimental design

Each replication draws a new data set from a fixed data-generating process and runs the engine exactly as the web page does. Replication r at size n uses numpy.random.default_rng([method_code, scenario_index, n, r]), so any replication can be rerun alone. Failures are counted, never discarded silently. Sizes n are the total number of observations (subjects for repeated-measures designs, studies for meta-analysis). A per-cell time budget of 45.0 s stops very slow cells early; the replications actually run are shown in every results table.

12.Diagnostics and interpretation

  • τ is the difference between the probabilities of concordance and discordance for a random pair, so values are smaller in magnitude than Pearson r (for a bivariate normal, τ = (2/π) arcsin ρ).

13.Computational limitations

  • O(n²) time and memory limit very large n in the browser.
  • tau-b and tau-a differ when ties are common; the engine reports tau-b.

Slowest simulated cell: 0.049 s per run (H0, t(3), n = 50), in CPython on a shared two-core machine. Browser speed with Pyodide is expected to be several times slower and was not measured.
