Linear discriminant analysis (LDA): technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

Linear discriminant analysis finds linear combinations of predictors that best separate known classes and classifies new observations with Gaussian class densities and a common covariance matrix.

2.Historical and theoretical background

Fisher (1936) derived the linear discriminant for the iris data.

3.Mathematical formulation

Within-class SSP W, between-class SSP B; discriminant directions are eigenvectors of W⁻¹B scaled to unit pooled within-class variance.
Classification rule: assign x to class k maximising δ_k(x) = x'Σ⁻¹μ_k − ½ μ_k'Σ⁻¹μ_k + log π_k.
Wilks' Λ tests of the discriminant functions use Bartlett's χ² approximation.
Accuracy: resubstitution and leave-one-out cross-validation (closed form where feasible, otherwise 10-fold); Mardia skewness is reported as a normality diagnostic within classes.

4.Statistical assumptions

  • Predictors multivariate normal within each class.
  • Equal covariance matrices across classes.
  • Independent observations; more observations than predictors.

5.Estimation algorithm

  • Pooled covariance, symmetric eigenproblem for W⁻¹B, posterior class probabilities from the discriminant scores, leave-one-out cross-validation (10-fold when the closed form is not feasible).

6.Computational implementation

  • Module oes/engine/oes_engine/stat_multivariate.py, function lda, registered as stat_lda in stat_registry.py.
  • Runtime dependencies: NumPy, pandas and SciPy only (the packages available in the browser Pyodide runtime); no backend.
  • Input validation: missing columns, empty data, non-numeric or constant variables, wrong number of groups, singular matrices and non-convergence return a plain-language error instead of an exception (tests in stat-validation/tests/test_stat_division.py).
  • Example run time: 0.04 s in CPython; real browser (Pyodide) timing has not been measured.

13.Computational limitations

  • Resubstitution accuracy is optimistic; use the cross-validated figure.
  • Unequal covariance matrices call for quadratic discriminant analysis, which is not included.

import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/iris.csv').read()
spec = {
    "vars": [
        "Sepal.Length",
        "Sepal.Width",
        "Petal.Length",
        "Petal.Width"
    ],
    "group": "Species"
}
result = o.run('stat_lda', csv, spec)
for t in result['tables']:
