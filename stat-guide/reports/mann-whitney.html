Mann-Whitney U test: technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

The Mann-Whitney U test compares two independent samples through their ranks and tests whether one tends to give larger values than the other.

2.Historical and theoretical background

Wilcoxon (1945) proposed the rank-sum form; Mann and Whitney (1947) gave the U form and the null distribution; Hodges and Lehmann (1963) supplied the associated location-shift estimator.

3.Mathematical formulation

U_1 = R_1 − n_1(n_1 + 1)/2, where R_1 is the rank sum of the first sample in the pooled data; U_2 = n_1 n_2 − U_1.
Exact null distribution (no ties): P(U = u) = c(u; n_1, n_2) / C(n_1 + n_2, n_1), c from the Gaussian binomial coefficient.
Normal approximation: z = (U − n_1n_2/2 ∓ 0.5) / σ_U with σ_U² = (n_1n_2/12) [(N + 1) − Σ(t³ − t)/(N(N − 1))] (tie-corrected).
Rank-biserial correlation r = 1 − 2U_1/(n_1n_2) (sign follows the first group); Hodges-Lehmann shift = median of all n_1n_2 pairwise differences, with a confidence interval from order statistics of those differences.

4.Statistical assumptions

  • Independent observations in two groups.
  • An ordinal or continuous outcome.
  • For the shift interpretation: the two distributions have the same shape. Without that, the test addresses P(X > Y) ≠ 1/2, not equality of medians.

5.Estimation algorithm

  • Mid-ranks of the pooled sample; exact enumeration by counting when no ties and n small; otherwise the tie-corrected normal approximation with optional continuity correction.

6.Computational implementation

7.Monte Carlo experimental design

Each replication draws a new data set from a fixed data-generating process and runs the engine exactly as the web page does. Replication r at size n uses numpy.random.default_rng([method_code, scenario_index, n, r]), so any replication can be rerun alone. Failures are counted, never discarded silently. Sizes n are the total number of observations (subjects for repeated-measures designs, studies for meta-analysis). A per-cell time budget of 45.0 s stops very slow cells early; the replications actually run are shown in every results table.

12.Diagnostics and interpretation

  • The rank-biserial correlation is the effect size: 0 means no tendency, ±1 complete separation.
  • A significant result means the probability that a draw from one group exceeds a draw from the other is not 1/2.

13.Computational limitations

  • With unequal spreads the test is no longer a test of location and its Type I error for 'equal medians' can exceed the nominal level.
  • The exact test is skipped when ties are present.

Slowest simulated cell: 0.015 s per run (H0, t(3), n = 100), in CPython on a shared two-core machine. Browser speed with Pyodide is expected to be several times slower and was not measured.
