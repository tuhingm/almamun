Random-effects meta-analysis: technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated, small-study tests unchecked Pooled estimate, tau2 and HKSJ interval match metafor published values and statsmodels; Egger and Begg tests were not cross-checked.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

Random-effects meta-analysis allows the true effect to vary between studies and estimates the mean of that distribution, the between-study variance τ² and a prediction interval.

2.Historical and theoretical background

DerSimonian and Laird (1986); REML and Paule-Mandel estimators of τ² compared by Viechtbauer (2005); the Hartung-Knapp-Sidik-Jonkman interval (Hartung and Knapp 2001).

3.Mathematical formulation

y_i = θ + u_i + e_i, u_i ~ N(0, τ²), e_i ~ N(0, v_i); w_i* = 1/(v_i + τ̂²); θ̂ = Σ w_i* y_i / Σ w_i*.
τ² estimators: DerSimonian-Laird (Q-moment), Hedges, Paule-Mandel (solves Q(τ²) = k − 1), ML and REML by Fisher scoring.
Wald interval θ̂ ± z SE, or Hartung-Knapp: θ̂ ± t_{k−1} sqrt(q* / (k − 1)) / sqrt(Σ w*) with q* = Σ w*(y − θ̂)².
95% prediction interval θ̂ ± t_{k−2} sqrt(τ̂² + SE²); Q-profile confidence interval for τ².

4.Statistical assumptions

  • True effects are normally distributed across studies.
  • Within-study variances known and correct.
  • Independent studies; enough studies (at least 5–10) to estimate τ².

5.Estimation algorithm

  • Iterative τ² estimators with bounds and convergence checks; Q-profile root finding; leave-one-out; Egger and Begg tests.

6.Computational implementation

  • Module oes/engine/oes_engine/stat_meta.py, function meta_random, registered as stat_meta_random in stat_registry.py.
  • Runtime dependencies: NumPy, pandas and SciPy only (the packages available in the browser Pyodide runtime); no backend.
  • Input validation: missing columns, empty data, non-numeric or constant variables, wrong number of groups, singular matrices and non-convergence return a plain-language error instead of an exception (tests in stat-validation/tests/test_stat_division.py).
  • Example run time: 0.03 s in CPython; real browser (Pyodide) timing has not been measured.

7.Monte Carlo experimental design

Each replication draws a new data set from a fixed data-generating process and runs the engine exactly as the web page does. Replication r at size n uses numpy.random.default_rng([method_code, scenario_index, n, r]), so any replication can be rerun alone. Failures are counted, never discarded silently. Sizes n are the total number of observations (subjects for repeated-measures designs, studies for meta-analysis). A per-cell time budget of 8.0 s stops very slow cells early; the replications actually run are shown in every results table.

12.Diagnostics and interpretation

  • Report the pooled effect with its Hartung-Knapp interval, τ², I² and the prediction interval: the latter says what a new study might show.

Diagnostics for this method are included in the result tables above.

13.Computational limitations

  • τ² is imprecise with few studies; the Wald interval undercovers then, and the Hartung-Knapp interval is preferred.
  • No meta-regression or multilevel models.

Slowest simulated cell: 0.487 s per run (tau2=0.1, REML + Wald, n = 200), in CPython on a shared two-core machine. Browser speed with Pyodide is expected to be several times slower and was not measured.
