Multivariate ANOVA (MANOVA): technical validation report

Sixteen-section technical report with simulation, benchmark and real-data results generated by the project code.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

This report validates an established method as implemented in OES. It does not claim a new estimator. All numbers were produced by the code in stat-validation/ and tools/make_stat_pages.py; the engine version was 1.5.0.

1.Methodological introduction

MANOVA tests whether group mean vectors of several continuous outcomes are equal, accounting for the correlation among the outcomes.

2.Historical and theoretical background

Wilks (1932) derived the likelihood-ratio criterion; Pillai (1955), Hotelling and Lawley contributed the alternative criteria; Rao (1951) gave the F approximation to Wilks' Λ.

3.Mathematical formulation

Model: Y = XB + E with rows of E ~ N_p(0, Σ).
H = between-group SSP matrix, E = within-group SSP matrix; the statistics are functions of the eigenvalues λ_s of E⁻¹H.
Wilks Λ = Π 1/(1 + λ_s); Pillai V = Σ λ_s/(1 + λ_s); Hotelling-Lawley U = Σ λ_s; Roy θ = λ_1/(1 + λ_1).
Rao's F approximation for Λ: F = [(1 − Λ^(1/t)) / Λ^(1/t)] · [(df2) / (df1)], t = sqrt[(p²q² − 4)/(p² + q² − 5)], with df1 = pq and df2 = wt − pq/2 + 1.

4.Statistical assumptions

  • Independent observations.
  • Multivariate normality within groups.
  • Equal covariance matrices across groups (Box's M is reported; it is sensitive to non-normality).
  • More observations than responses within each group.

5.Estimation algorithm

  • SSP matrices by least squares; eigenvalues of E⁻¹H by a symmetric reduction; the four statistics with their F approximations; follow-up univariate ANOVAs with Holm adjustment.

6.Computational implementation

  • Module oes/engine/oes_engine/stat_anova.py, function manova, registered as stat_manova in stat_registry.py.
  • Runtime dependencies: NumPy, pandas and SciPy only (the packages available in the browser Pyodide runtime); no backend.
  • Input validation: missing columns, empty data, non-numeric or constant variables, wrong number of groups, singular matrices and non-convergence return a plain-language error instead of an exception (tests in stat-validation/tests/test_stat_division.py).
  • Example run time: 0.02 s in CPython; real browser (Pyodide) timing has not been measured.

12.Diagnostics and interpretation

  • A significant multivariate test says at least one outcome differs on some linear combination; the univariate follow-ups show where.
  • Partial η² = 1 − Λ^(1/s) is the multivariate effect size.

13.Computational limitations

  • Roy's largest root has only an upper-bound F approximation; it is reported as such.
  • Wilks' Λ and Pillai's trace can disagree when assumptions fail; Pillai's trace is the more robust.
