Parametric survival (Weibull, exponential, log-normal)

Parametric survival models fit exponential, Weibull, log-normal and log-logistic distributions to censored data and compare them by information criteria and against the Kaplan-Meier curve.

Overview

Parametric survival models fit exponential, Weibull, log-normal and log-logistic distributions to censored data and compare them by information criteria and against the Kaplan-Meier curve.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

The same accelerated-failure-time likelihood as the AFT model, estimated separately for each distribution.
AIC = −2ℓ + 2k, BIC = −2ℓ + k log(n_events); Akaike weights w_m = exp(−Δ_m/2)/Σ exp(−Δ/2).
Fitted survival is compared with Kaplan-Meier through the maximum absolute and root-mean-square differences.

Assumptions

  • One of the candidate distributions is adequate.
  • Non-informative censoring.

Diagnostics and interpretation

  • Prefer the lowest AIC but check the distance to the Kaplan-Meier curve and the plot of fitted and empirical survival.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • Choosing by AIC does not prove the chosen distribution is right; with small samples AIC often picks the wrong family (see the selection-frequency runs).

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/veteran.csv').read()
spec = {
    "time": "time",
    "event": "status",
    "covariates": [
        "karno"
    ]
}
result = o.run('stat_parametric', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
