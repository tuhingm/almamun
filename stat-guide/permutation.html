Permutation tests

Permutation tests obtain the null distribution of a statistic by re-labelling the data in all (or randomly many) exchangeable ways, giving exact or near-exact p-values under minimal assumptions.

Overview

Permutation tests obtain the null distribution of a statistic by re-labelling the data in all (or randomly many) exchangeable ways, giving exact or near-exact p-values under minimal assumptions.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

For T(x, labels) and M rearrangements: exact p = #{|T*| ≥ |T_obs|}/M_all; Monte Carlo p = (b + 1)/(m + 1), b = #{|T*| ≥ |T_obs|}.
Tests: difference in means or medians, paired (sign flipping), correlation, one-way F.
Exact enumeration when the number of rearrangements does not exceed exact_max.

Assumptions

  • Exchangeability of the labels under H0 (this is stronger than equal means: the null is equality of the whole distributions).

Estimation algorithm

  • Combinatorial enumeration or seeded random permutations; two-sided p by comparing |T|.

Diagnostics and interpretation

  • The exact p-value is the proportion of rearrangements at least as extreme as the data; the reference Welch test is shown for contrast.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • A test of the mean difference with unequal variances is not exact for the equal-means null (see the robustness runs).
  • Monte Carlo p-values have sampling error, reported.

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/toothgrowth.csv').read()
spec = {
    "test": "mean_diff",
    "y": "len",
    "group": "supp",
    "n_perm": 20000,
    "seed": 12345
}
result = o.run('stat_permutation', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
