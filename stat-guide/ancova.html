Analysis of covariance (ANCOVA)

ANCOVA compares group means after adjusting for one or more continuous covariates, increasing precision and removing covariate imbalance.

Overview

ANCOVA compares group means after adjusting for one or more continuous covariates, increasing precision and removing covariate imbalance.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

Model: y_ij = μ + α_i + Σ β_k (x_kij − x̄_k) + ε_ij.
Type III F test of the group effect: F = [(SSE_reduced − SSE_full) / (k − 1)] / [SSE_full / (N − k − p)].
Adjusted mean of group i: ȳ_i − Σ β̂_k (x̄_ki − x̄_k); pairwise differences use the t distribution with the residual df and the standard error of a contrast of the fitted coefficients.

Assumptions

  • Linear relation between covariate and outcome, with the same slope in every group (homogeneity of regression slopes; tested and reported).
  • Covariates measured without error and unaffected by the treatment.
  • Independent normal errors with constant variance.

Estimation algorithm

  • OLS with effect-coded groups plus covariates; hypothesis tests from nested fits; adjusted means from predictions at the covariate means; Holm-adjusted pairwise contrasts.

Diagnostics and interpretation

  • The adjusted differences answer 'what would the group difference be at equal covariate values'.
  • If the slope-homogeneity test rejects, report the interaction rather than the adjusted means.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • A covariate that is itself affected by the grouping variable biases the adjusted difference.
  • Non-parallel slopes make a single adjusted difference misleading.

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/anorexia.csv').read()
spec = {
    "y": "Postwt",
    "group": "Treat",
    "covariates": [
        "Prewt"
    ]
}
result = o.run('stat_ancova', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
