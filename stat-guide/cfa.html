Confirmatory factor analysis (CFA)

Confirmatory factor analysis tests a pre-specified measurement model in which each indicator loads on named latent factors, estimated by maximum likelihood on the covariance structure.

Overview

Confirmatory factor analysis tests a pre-specified measurement model in which each indicator loads on named latent factors, estimated by maximum likelihood on the covariance structure.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

x = Λ ξ + δ, Σ(θ) = Λ Φ Λ' + Θ_δ, with a marker loading fixed at 1 (or factor variances fixed at 1) for identification.
F_ML(θ) = log|Σ(θ)| + tr(S Σ(θ)⁻¹) − log|S| − p; χ² = (n − 1) F̂_ML with df = p(p + 1)/2 − q (q free parameters).
Standard errors from the inverse of the information matrix (observed Hessian of the ML discrepancy); fit indices CFI, TLI, RMSEA (with CI) and SRMR.

Assumptions

  • Multivariate normality (the standard errors and χ² are not robust to its violation; the simulation shows the effect).
  • A correctly specified, identified model: at least three indicators per factor, or two with correlated factors.
  • Large sample size (a common minimum is 100–200).

Estimation algorithm

  • lavaan-style syntax parser; BFGS on the ML discrepancy with analytic gradient (restarted once if it stops early); Hessian-based standard errors; fit indices and the matrix of residual correlations as local-misfit diagnostics; Heywood (negative variance) cases flagged.

Diagnostics and interpretation

  • Judge fit by several indices together (CFI/TLI above about 0.95, RMSEA below about 0.06, SRMR below about 0.08 are conventional); standardised loadings are comparable across indicators.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • Maximum-likelihood with normal theory only: no robust (Satorra-Bentler) or categorical estimators.
  • Only measurement models: no regressions among latent variables.

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/holzinger_swineford.csv').read()
spec = {
    "model": "visual =~ x1 + x2 + x3\ntextual =~ x4 + x5 + x6\nspeed =~ x7 + x8 + x9"
}
result = o.run('stat_cfa', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
