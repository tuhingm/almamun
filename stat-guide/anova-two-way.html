Two-way ANOVA

Two-way ANOVA tests the effects of two crossed factors and their interaction on a continuous outcome, with Type II or Type III sums of squares for unbalanced data.

Overview

Two-way ANOVA tests the effects of two crossed factors and their interaction on a continuous outcome, with Type II or Type III sums of squares for unbalanced data.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

Model: y_ijk = μ + α_i + β_j + (αβ)_ij + ε_ijk, ε ~ N(0, σ²), with sum-to-zero (effect) coding.
Type III SS of a term = SS_residual(model without the term) − SS_residual(full model), each term adjusted for all others; Type II adjusts for terms that do not contain it.
F = (SS_term / df_term) / MS_residual ~ F(df_term, df_res).
Partial η² = SS_term / (SS_term + SS_res), with a confidence interval from the noncentral F distribution.

Assumptions

  • Independent observations.
  • Normal errors with constant variance across cells (Levene/Brown-Forsythe is reported).
  • No empty cells when the interaction is included.

Estimation algorithm

  • Nested least-squares fits with effect-coded design matrices; term SS by differences of residual SS; estimated marginal means as unweighted means of cell means.

Diagnostics and interpretation

  • Read the interaction first: if it is significant, describe effects of one factor at each level of the other.
  • Partial η² is comparable across terms within one analysis.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • Main effects are hard to interpret when the interaction is large.
  • Type III results depend on the coding; the engine fixes sum-to-zero coding, which is the convention that makes Type III meaningful.

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/toothgrowth.csv').read()
spec = {
    "y": "len",
    "factor_a": "supp",
    "factor_b": "dose",
    "ss_type": "III"
}
result = o.run('stat_anova2', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
