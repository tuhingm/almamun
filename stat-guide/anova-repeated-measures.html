Repeated-measures ANOVA

Repeated-measures ANOVA tests whether the mean outcome differs across conditions or time points measured on the same subjects, using the subject-by-condition interaction as the error term.

Overview

Repeated-measures ANOVA tests whether the mean outcome differs across conditions or time points measured on the same subjects, using the subject-by-condition interaction as the error term.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

Model: y_ij = μ + π_i + τ_j + ε_ij with subject effects π_i and condition effects τ_j.
F = [SS_cond / (k − 1)] / [SS_subj×cond / ((n − 1)(k − 1))] ~ F(k − 1, (n − 1)(k − 1)) under sphericity.
Greenhouse-Geisser ε̂ = (tr S*)² / [(k − 1) tr(S*²)], where S* is the double-centred covariance matrix of the k measurements; corrected df = ε̂(k − 1) and ε̂(n − 1)(k − 1).
Huynh-Feldt ε̃ = [n(k − 1)ε̂ − 2] / [(k − 1)(n − 1 − (k − 1)ε̂)], truncated at 1.
Generalised η²_G = SS_cond / (SS_cond + SS_subj + SS_error).

Assumptions

  • Each subject is measured under every condition (a complete balanced design; subjects with a missing condition are dropped and reported).
  • Multivariate normality of the k measurements.
  • Sphericity: equal variances of all pairwise differences (tested by Mauchly; the corrections relax it).

Estimation algorithm

  • Two-way decomposition of sums of squares by subject and condition; Mauchly's W on the orthonormal contrasts; ε corrections; Holm-adjusted paired t tests as follow-up.

Diagnostics and interpretation

  • Report the corrected p-value when ε̂ is well below 1 (a rule of thumb is below 0.75).
  • Generalised η² allows comparison with between-subjects designs.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • Only one within-subject factor and no between-subject factors; use the linear mixed model (E1) for more complex designs or unbalanced data.
  • Mauchly's test has low power in small samples and is oversensitive in large ones, so the automatic correction rule is a convention, not a proof.

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/sleepstudy.csv').read()
spec = {
    "subject": "Subject",

    "y": "Reaction"
}
