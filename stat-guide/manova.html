Multivariate ANOVA (MANOVA)

MANOVA tests whether group mean vectors of several continuous outcomes are equal, accounting for the correlation among the outcomes.

Overview

MANOVA tests whether group mean vectors of several continuous outcomes are equal, accounting for the correlation among the outcomes.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

Model: Y = XB + E with rows of E ~ N_p(0, Σ).
H = between-group SSP matrix, E = within-group SSP matrix; the statistics are functions of the eigenvalues λ_s of E⁻¹H.
Wilks Λ = Π 1/(1 + λ_s); Pillai V = Σ λ_s/(1 + λ_s); Hotelling-Lawley U = Σ λ_s; Roy θ = λ_1/(1 + λ_1).
Rao's F approximation for Λ: F = [(1 − Λ^(1/t)) / Λ^(1/t)] · [(df2) / (df1)], t = sqrt[(p²q² − 4)/(p² + q² − 5)], with df1 = pq and df2 = wt − pq/2 + 1.

Assumptions

  • Independent observations.
  • Multivariate normality within groups.
  • Equal covariance matrices across groups (Box's M is reported; it is sensitive to non-normality).
  • More observations than responses within each group.

Estimation algorithm

  • SSP matrices by least squares; eigenvalues of E⁻¹H by a symmetric reduction; the four statistics with their F approximations; follow-up univariate ANOVAs with Holm adjustment.

Diagnostics and interpretation

  • A significant multivariate test says at least one outcome differs on some linear combination; the univariate follow-ups show where.
  • Partial η² = 1 − Λ^(1/s) is the multivariate effect size.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • Roy's largest root has only an upper-bound F approximation; it is reported as such.
  • Wilks' Λ and Pillai's trace can disagree when assumptions fail; Pillai's trace is the more robust.

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/iris.csv').read()
spec = {
    "y_vars": [
        "Sepal.Length",
        "Sepal.Width",
        "Petal.Length",
        "Petal.Width"
    ],
    "group": "Species"
}
result = o.run('stat_manova', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
