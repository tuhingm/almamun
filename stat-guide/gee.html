Generalised estimating equations (GEE)

Generalised estimating equations estimate population-averaged regression effects for clustered or longitudinal data with robust standard errors that remain valid when the working correlation is misspecified.

Overview

Generalised estimating equations estimate population-averaged regression effects for clustered or longitudinal data with robust standard errors that remain valid when the working correlation is misspecified.

Validated with a documented deviation Independence/exchangeable match statsmodels; AR(1) with estimated alpha uses a different moment estimator (see limitations); QIC follows Pan (2001) and differs from statsmodels' QIC.

Mathematical formulation

Estimating equation: Σ_i D_i' V_i⁻¹ (y_i − μ_i) = 0, V_i = φ A_i^{1/2} R(α) A_i^{1/2}.
Robust (sandwich) covariance: B⁻¹ M B⁻¹ with B = Σ D'V⁻¹D and M = Σ D'V⁻¹ (y − μ)(y − μ)' V⁻¹ D.
Working correlation: independence, exchangeable (α from the moment estimator), AR(1).
QIC = −2Q(β̂) + 2 tr(Ω̂_I V̂_R), as defined by Pan (2001).

Assumptions

  • Correct mean model and link; independent clusters.
  • Missing data completely at random (GEE is not valid under MAR without weighting).
  • Enough clusters (about 30 or more) for the sandwich estimator to be reliable.

Estimation algorithm

  • Iteratively reweighted fitting with moment estimates of the scale and α; the sandwich estimator; naive SE reported alongside.

Diagnostics and interpretation

  • Coefficients are marginal effects (average over clusters); use the robust SE and its confidence interval, not the naive ones.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • The AR(1) correlation parameter is estimated by a different moment estimator than the one in statsmodels: with α fixed at the same value the coefficients agree exactly, but with α estimated they can differ (in the binomial benchmark by up to 0.55), so AR(1) results should be read as one valid GEE fit, not as a statsmodels replica.
  • statsmodels' QIC omits a weighting of Pan's trace term; the engine follows Pan's definition, so QIC values differ although QICu agrees exactly.

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/orthodont.csv').read()
spec = {
    "y": "distance",
    "group": "Subject",
    "time": "age",
    "covariates": [
        "age",
        "Sex01"
    ],
    "family": "gaussian",
    "corr": "exchangeable"
}
result = o.run('stat_gee', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
