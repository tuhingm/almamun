Accelerated failure time model

Accelerated failure time models relate covariates to the logarithm of survival time: a covariate multiplies the time scale rather than the hazard.

Overview

Accelerated failure time models relate covariates to the logarithm of survival time: a covariate multiplies the time scale rather than the hazard.

Validated Compared with reference software on identical data and specifications, and checked by Monte Carlo simulation.

Run it on your dataTechnical validation report

Mathematical formulation

log T = x'β + σ W, with W the standardised error: extreme-value (Weibull), normal (log-normal), logistic (log-logistic), or extreme-value with σ = 1 (exponential).
Log-likelihood: Σ δ_i [log f_W(w_i) − log σ] + (1 − δ_i) log S_W(w_i), w_i = (log t_i − x_i'β)/σ.
Maximised by BFGS from several starts and polished by Newton steps with analytic gradient; SE from the numerical Hessian; time ratio = exp(β).

Assumptions

  • The chosen error distribution is correct.
  • Non-informative censoring.
  • Covariates act multiplicatively on survival time.

Estimation algorithm

  • Log-σ parameterisation to enforce positivity; analytic gradient; numerical Hessian for the covariance matrix; likelihood-ratio test against the intercept-only model.

Diagnostics and interpretation

  • exp(β) is a time ratio: 1.3 means survival times are 30% longer per unit of the covariate.

The diagnostic tables are part of the results above (assumption checks, fit statistics, residual or goodness-of-fit tables).

Limitations

  • Coefficients are not comparable across distributions with different error laws.
  • A wrong error distribution biases the estimates (see the misspecification run).

Replication code

# run from the repository root (needs numpy, pandas, scipy)
import sys; sys.path.insert(0, 'oes/engine')
import oes_engine as o
csv = open('stat-guide/examples/rossi.csv').read()
spec = {
    "time": "week",
    "event": "arrest",
    "covariates": [
        "fin",
        "age",
        "prio"
    ],
    "distribution": "weibull"
}
result = o.run('stat_aft', csv, spec)
for t in result['tables']:
    print(t['title']); print(t['columns']); [print(r) for r in t['rows'][:10]]
