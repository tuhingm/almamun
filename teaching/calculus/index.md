# Calculus: Mathematical Methods for Economics and Statistics

**Level:** Undergraduate foundations with graduate mathematical extensions  
**Coverage:** Real analysis foundations, single- and multivariable calculus, optimization, integration, and dynamic systems.

## Course overview
This course develops calculus from definitions and mathematical arguments through applications in economics, statistics, and dynamic modeling. Each lecture includes objectives, mathematical development, worked examples, problem sets, a computational exercise, and readings.

## Learning outcomes
Students will be able to:
- Prove basic limit and continuity results using epsilon-delta arguments.
- Analyze sequences and series using rigorous convergence criteria.
- Differentiate and integrate single-variable functions.
- Apply Taylor approximations, convexity, and optimization conditions.
- Analyze multivariate functions using gradients, Jacobians, and Hessians.
- Solve equality- and inequality-constrained optimization problems.
- Use implicit and inverse function theorems for comparative statics.
- Evaluate multiple integrals and probability transformations.
- Analyze continuous- and discrete-time dynamic systems.
