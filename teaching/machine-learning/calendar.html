SESSION PLAN

Course Calendar

The course is organized into 15 sessions. The schedule can be adapted to semester length and instructor availability.

SessionTopicPreparation
01Foundations of Statistical Learning
Learning problems, prediction targets, feature spaces, loss functions, empirical risk minimization, generalization and the bias–variance trade-off.
Read lecture notes and prepare discussion questions.
02Linear Models, Regularization and Feature Engineering
Least squares prediction, polynomial and interaction features, ridge, lasso, elastic net, scaling and feature selection.
Read lecture notes and prepare discussion questions.
03Classification and Logistic Regression
Binary outcomes, logistic likelihood, odds and log-odds, decision thresholds, multiclass classification and calibration.
Read lecture notes and prepare discussion questions.
04Model Assessment and Resampling
Train-validation-test splits, k-fold cross-validation, bootstrap, nested cross-validation, leakage and uncertainty in performance estimates.
Read lecture notes and prepare discussion questions.
05Decision Trees
Recursive partitioning, impurity measures, pruning, cost-complexity, regression trees and classification trees.
Read lecture notes and prepare discussion questions.
06Bagging and Random Forests
Bootstrap aggregation, variance reduction, random feature subsampling, out-of-bag error, permutation importance.
Read lecture notes and prepare discussion questions.
07Boosting and Gradient Boosting
Weak learners, additive expansions, gradient boosting, learning rate, tree depth, shrinkage and early stopping.
Read lecture notes and prepare discussion questions.
08Support Vector Machines and Kernel Methods
Maximum-margin classification, soft margins, hinge loss, support vectors, kernel functions and tuning.
Read lecture notes and prepare discussion questions.
09Unsupervised Learning and Clustering
Distance metrics, k-means, hierarchical clustering, linkage, mixture-model intuition and cluster validation.
Read lecture notes and prepare discussion questions.
10Dimension Reduction and Principal Components
Covariance matrices, eigenvectors, singular value decomposition, explained variance and principal-component scores.
Read lecture notes and prepare discussion questions.
11Neural Networks and Deep Learning
Perceptrons, multilayer networks, activation functions, backpropagation, regularization, optimization and validation.
Read lecture notes and prepare discussion questions.
12Interpretation, Responsible Deployment and Reproducibility
Permutation importance, partial dependence, SHAP overview, subgroup performance, drift, reproducible pipelines and model documentation.
Read lecture notes and prepare discussion questions.
13Model Selection and Hyperparameter Optimization
Grid and randomized search, Bayesian optimization, nested cross-validation, computational budgets and selection bias.
Read lecture notes and prepare discussion questions.
14Causal Machine Learning and Heterogeneous Treatment Effects
Prediction versus causal inference, nuisance functions, orthogonalization, double machine learning, cross-fitting and causal forests.
Read lecture notes and prepare discussion questions.
15Integrated Machine Learning Project and Reproducible Reporting
End-to-end workflow, model comparison, uncertainty, interpretation, deployment monitoring and technical communication.
Read lecture notes and prepare discussion questions.
