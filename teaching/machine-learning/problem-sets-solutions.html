Assignments and Exercises

Assignments are designed to connect conceptual understanding with transparent applied work.

Problem sets

  1. Problem set 1: Foundations of Statistical Learning — summarize the central framework, complete an applied exercise and discuss limitations.
  2. Problem set 2: Linear Models, Regularization and Feature Engineering — summarize the central framework, complete an applied exercise and discuss limitations.
  3. Problem set 3: Classification and Logistic Regression — summarize the central framework, complete an applied exercise and discuss limitations.
  4. Problem set 4: Model Assessment and Resampling — summarize the central framework, complete an applied exercise and discuss limitations.
  5. Problem set 5: Decision Trees — summarize the central framework, complete an applied exercise and discuss limitations.
  6. Problem set 6: Bagging and Random Forests — summarize the central framework, complete an applied exercise and discuss limitations.
  7. Problem set 7: Boosting and Gradient Boosting — summarize the central framework, complete an applied exercise and discuss limitations.
  8. Problem set 8: Support Vector Machines and Kernel Methods — summarize the central framework, complete an applied exercise and discuss limitations.
  9. Problem set 9: Unsupervised Learning and Clustering — summarize the central framework, complete an applied exercise and discuss limitations.
  10. Problem set 10: Dimension Reduction and Principal Components — summarize the central framework, complete an applied exercise and discuss limitations.
  11. Problem set 11: Neural Networks and Deep Learning — summarize the central framework, complete an applied exercise and discuss limitations.
  12. Problem set 12: Interpretation, Responsible Deployment and Reproducibility — summarize the central framework, complete an applied exercise and discuss limitations.

Applied project

Select a prediction problem and dataset. Define the target, build a baseline, compare at least three algorithms, use a defensible validation design, tune hyperparameters without leakage, interpret errors and submit reproducible code.

Submission standards

  • State the question, data sources and definitions.
  • Show analytical steps and provide reproducible materials where relevant.
  • Distinguish descriptive findings from causal or normative claims.
  • Discuss limitations and cite all sources.
