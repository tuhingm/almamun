LECTURE 13 / 15

Model Selection, Hyperparameter Optimization and Automated Tuning

Grid and randomized search, Bayesian optimization, nested cross-validation, computational budgets, selection bias and reproducible tuning.

Learning objectives

  1. Define the key concepts and analytical questions for this session.
  2. Explain the underlying framework, assumptions and methodological choices.
  3. Apply the framework to a structured empirical or policy problem.
  4. Interpret findings and communicate implications and limitations.

1. Conceptual framework

Grid and randomized search, Bayesian optimization, nested cross-validation, computational budgets, selection bias and reproducible tuning. Begin by defining the unit of analysis, target outcome and decision context. Distinguish the descriptive question from the explanatory or causal question, and make the assumptions behind the proposed analysis explicit.

2. Analytical development

Design a nested validation strategy and explain how hyperparameter search can overfit the validation process. A rigorous application should document data sources, variable construction, analytical choices and uncertainty. Compare a baseline approach with a defensible alternative, and evaluate whether conclusions are robust to reasonable changes in assumptions or implementation.

Key analytical principle.

Interpret results relative to the target question, measurement choices, identifying assumptions and relevant comparison. Report limitations and uncertainty alongside substantive findings.

3. Worked application

Construct an applied case with a clearly defined research question, relevant population or dataset, measurable outcomes and a transparent analytical plan. Specify the baseline, conduct an alternative or sensitivity analysis, and prepare a concise interpretation that distinguishes evidence from assumptions.

Practical example: Nested cross-validation for model selection

Tune an SVM in inner folds and estimate the entire tuning procedure in outer folds. The outer-fold scores provide a less selection-biased estimate than the best inner-CV score.

Python implementation. Run this reproducible example with NumPy and scikit-learn (and pandas/joblib where imported).

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import GridSearchCV, StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
import numpy as np
X,y=load_breast_cancer(return_X_y=True)
pipe=make_pipeline(StandardScaler(),SVC())
grid={'svc__C':[.1,1,10],'svc__gamma':['scale',.01,.1]}
inner=StratifiedKFold(n_splits=4,shuffle=True,random_state=13)
outer=StratifiedKFold(n_splits=5,shuffle=True,random_state=14)
search=GridSearchCV(pipe,grid,cv=inner,scoring='roc_auc')
scores=cross_val_score(search,X,y,cv=outer,scoring='roc_auc')
print('Outer-fold AUC:',np.round(scores,3))
print('Mean nested-CV AUC:',round(scores.mean(),3))

Interpretation task. Explain the output, connect it to the lecture's method, and state one limitation.

4. Discussion questions

  • What is the principal target, estimand or policy objective?
  • Which assumptions are required for the analysis?
  • What sources of heterogeneity or measurement error matter?
  • Which robustness checks would materially strengthen the conclusion?

Problem set

  1. Explain the main framework and its assumptions.
  2. Work through a small numerical, computational or policy example.
  3. Identify two limitations and propose suitable sensitivity checks.

Applied activity

Complete a reproducible notebook using Python or R. Document preprocessing, model specification, validation, tuning, interpretation and limitations.
