LECTURE 15 / 15

Integrated Machine Learning Project and Reproducible Reporting

End-to-end workflow, data provenance, preprocessing pipelines, model comparison, uncertainty, interpretation, deployment monitoring and technical communication.

Learning objectives

  1. Define the key concepts and analytical questions for this session.
  2. Explain the underlying framework, assumptions and methodological choices.
  3. Apply the framework to a structured empirical or policy problem.
  4. Interpret findings and communicate implications and limitations.

1. Conceptual framework

End-to-end workflow, data provenance, preprocessing pipelines, model comparison, uncertainty, interpretation, deployment monitoring and technical communication. Begin by defining the unit of analysis, target outcome and decision context. Distinguish the descriptive question from the explanatory or causal question, and make the assumptions behind the proposed analysis explicit.

2. Analytical development

Present a reproducible analysis from research question and data preparation through validation, interpretation and limitations. A rigorous application should document data sources, variable construction, analytical choices and uncertainty. Compare a baseline approach with a defensible alternative, and evaluate whether conclusions are robust to reasonable changes in assumptions or implementation.

Key analytical principle.

Interpret results relative to the target question, measurement choices, identifying assumptions and relevant comparison. Report limitations and uncertainty alongside substantive findings.

3. Worked application

Construct an applied case with a clearly defined research question, relevant population or dataset, measurable outcomes and a transparent analytical plan. Specify the baseline, conduct an alternative or sensitivity analysis, and prepare a concise interpretation that distinguishes evidence from assumptions.

Practical example: An end-to-end reproducible classification workflow

Build a leakage-safe classification pipeline. Imputation and scaling occur inside the cross-validation pipeline; tune on training data, evaluate once on the test set and save the fitted estimator.

Python implementation. Run this reproducible example with NumPy and scikit-learn (and pandas/joblib where imported).

import joblib
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score, classification_report
X,y=make_classification(n_samples=800,n_features=12,n_informative=6,weights=[.7,.3],random_state=15)
Xtr,Xte,ytr,yte=train_test_split(X,y,test_size=.25,stratify=y,random_state=15)
pipe=make_pipeline(SimpleImputer(strategy='median'),StandardScaler(),LogisticRegression(max_iter=2000))
search=GridSearchCV(pipe,{'logisticregression__C':[.01,.1,1,10]},cv=5,scoring='roc_auc').fit(Xtr,ytr)
prob=search.predict_proba(Xte)[:,1]
print('Test ROC-AUC:',round(roc_auc_score(yte,prob),3))
print(classification_report(yte,search.predict(Xte)))
joblib.dump(search.best_estimator_,'ml_course_pipeline.joblib')

Interpretation task. Explain the output, connect it to the lecture's method, and state one limitation.

4. Discussion questions

  • What is the principal target, estimand or policy objective?
  • Which assumptions are required for the analysis?
  • What sources of heterogeneity or measurement error matter?
  • Which robustness checks would materially strengthen the conclusion?

Problem set

  1. Explain the main framework and its assumptions.
  2. Work through a small numerical, computational or policy example.
  3. Identify two limitations and propose suitable sensitivity checks.

Applied activity

Complete a reproducible notebook using Python or R. Document preprocessing, model specification, validation, tuning, interpretation and limitations.
