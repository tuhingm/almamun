LECTURE 03 / 12

Classification and Logistic Regression

Binary outcomes, logistic likelihood, odds and log-odds, decision thresholds, multiclass classification and calibration.

Learning objectives

  1. Define the central concepts and terminology used in this session.
  2. Explain the analytical framework and its assumptions.
  3. Apply the framework to a structured example or policy problem.
  4. Interpret results and communicate their implications.

1. Conceptual framework

Binary outcomes, logistic likelihood, odds and log-odds, decision thresholds, multiclass classification and calibration. The central analytical task is to identify the question being addressed, define the relevant units and outcomes, and make the assumptions behind the analysis explicit. Distinguish descriptive evidence, explanatory mechanisms and normative criteria before drawing conclusions.

2. Analytical development

Interpret exp(βj) as a conditional odds ratio and distinguish probability estimation from class assignment.

Organize the analysis around a clear sequence: define the target concept; specify the relevant variables or dimensions; state the assumptions; select an appropriate method; and assess the sensitivity of the interpretation to alternative definitions or design choices.

Key analytical principle.

A result is interpretable only relative to its target, assumptions, measurement choices and comparison group. Report these elements alongside the result rather than treating a numerical output as self-explanatory.

3. Worked application

Consider a hypothetical applied study. Begin by stating the research or policy question, identify the population of interest, and define the outcome or performance criterion. Assemble the relevant data, document missingness and measurement limitations, and produce a transparent baseline analysis. Then compare at least one alternative specification or scenario and explain whether the substantive conclusion changes.

Practical example: Logistic classification of loan default

Estimate the probability of loan default from debt-to-income ratio and missed payments. Convert predicted probabilities into classifications at a chosen threshold and inspect precision and recall.

Python implementation. Run this cell in a Python environment with scikit-learn, NumPy and pandas where used. The data are simulated so the exercise is immediately reproducible.

import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, roc_auc_score

rng = np.random.default_rng(31)
X = rng.normal(size=(600, 2))
p = 1 / (1 + np.exp(-(-1.0 + 1.1*X[:, 0] + 1.5*X[:, 1])))
y = rng.binomial(1, p)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=.3, stratify=y, random_state=8)
model = make_pipeline(StandardScaler(), LogisticRegression())
model.fit(Xtr, ytr)
prob = model.predict_proba(Xte)[:, 1]
pred = (prob >= .35).astype(int)
print("ROC-AUC:", round(roc_auc_score(yte, prob), 3))
print(classification_report(yte, pred, zero_division=0))

Interpretation task. Record the reported metric or output, explain what it measures, and identify one limitation before drawing a substantive conclusion.

4. Discussion

  • What is the principal estimand, concept or decision criterion?
  • Which assumptions are necessary for the analysis?
  • Which groups or dimensions may be hidden by an aggregate result?
  • What additional evidence would improve the interpretation?

Problem set

  1. Define the main concepts from this lecture and explain their relationships.
  2. Construct a small numerical or conceptual example illustrating the main method.
  3. Identify two limitations and propose a robustness or triangulation strategy.

Applied activity

Using a public or simulated dataset, implement the method in Python or R. Record preprocessing decisions, validation design, tuning choices and performance measures.

Further reading

Consult the core textbook and primary methodological references listed on the course Readings page. Supplement the reading with current statistical publications and official datasets relevant to the application.
