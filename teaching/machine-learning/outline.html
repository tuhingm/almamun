Topic Outline

Module 1: Foundations of Statistical Learning

Learning problems, prediction targets, feature spaces, loss functions, empirical risk minimization, generalization and the bias–variance trade-off.

Core task: Define a prediction rule as f: X → Y and distinguish training risk from expected prediction risk.

Module 2: Linear Models, Regularization and Feature Engineering

Least squares prediction, polynomial and interaction features, ridge, lasso, elastic net, scaling and feature selection.

Core task: Compare OLS and ridge estimates; explain how the penalty changes variance and coefficient shrinkage.

Module 3: Classification and Logistic Regression

Binary outcomes, logistic likelihood, odds and log-odds, decision thresholds, multiclass classification and calibration.

Core task: Interpret exp(βj) as a conditional odds ratio and distinguish probability estimation from class assignment.

Module 4: Model Assessment and Resampling

Train-validation-test splits, k-fold cross-validation, bootstrap, nested cross-validation, leakage and uncertainty in performance estimates.

Core task: Use nested cross-validation to separate hyperparameter selection from final performance assessment.

Module 5: Decision Trees

Recursive partitioning, impurity measures, pruning, cost-complexity, regression trees and classification trees.

Core task: Explain how Gini impurity and entropy select candidate splits and why pruning controls complexity.

Module 6: Bagging and Random Forests

Bootstrap aggregation, variance reduction, random feature subsampling, out-of-bag error, permutation importance.

Core task: Explain why averaging decorrelated trees can reduce prediction variance.

Module 7: Boosting and Gradient Boosting

Weak learners, additive expansions, gradient boosting, learning rate, tree depth, shrinkage and early stopping.

Core task: Interpret boosting as stage-wise optimization of a differentiable empirical loss.

Module 8: Support Vector Machines and Kernel Methods

Maximum-margin classification, soft margins, hinge loss, support vectors, kernel functions and tuning.

Core task: Explain the role of C and kernel bandwidth in the margin-complexity trade-off.

Module 9: Unsupervised Learning and Clustering

Distance metrics, k-means, hierarchical clustering, linkage, mixture-model intuition and cluster validation.

Core task: Evaluate cluster stability and explain why scaling and distance choice affect partitions.

Module 10: Dimension Reduction and Principal Components

Covariance matrices, eigenvectors, singular value decomposition, explained variance and principal-component scores.

Core task: Derive the first principal component as the unit direction maximizing projected sample variance.

Module 11: Neural Networks and Deep Learning

Perceptrons, multilayer networks, activation functions, backpropagation, regularization, optimization and validation.

Core task: Trace forward propagation and explain gradient-based parameter updates.

Module 12: Interpretation, Responsible Deployment and Reproducibility

Permutation importance, partial dependence, SHAP overview, subgroup performance, drift, reproducible pipelines and model documentation.

Core task: Prepare a model card and evaluate whether aggregate metrics conceal subgroup error differences.

Module 13: Model Selection and Hyperparameter Optimization

Grid and randomized search, Bayesian optimization, nested cross-validation, computational budgets and selection bias.

Core task: Design nested validation and explain how hyperparameter search can overfit validation data.

Module 14: Causal Machine Learning and Heterogeneous Treatment Effects

Prediction versus causal inference, nuisance functions, orthogonalization, double machine learning, cross-fitting and causal forests.

Core task: Distinguish predictive risk from causal estimands and explain cross-fitting.

Module 15: Integrated Machine Learning Project and Reproducible Reporting

End-to-end workflow, model comparison, uncertainty, interpretation, deployment monitoring and technical communication.

Core task: Present a reproducible analysis from research question and data preparation through validation and interpretation.
