Readings and Resources

Use the following core references as a foundation. Each lecture should be supplemented with current research, official data and subject-specific readings.

Core textbooks

  • James, Witten, Hastie and Tibshirani, An Introduction to Statistical Learning.
  • Hastie, Tibshirani and Friedman, The Elements of Statistical Learning.
  • Murphy, Probabilistic Machine Learning: An Introduction.
  • Bishop, Pattern Recognition and Machine Learning.

Computational resources

  • scikit-learn user guide and API documentation.
  • PyTorch documentation and tutorials.
  • tidymodels documentation for R workflows.

Reading strategy

Start with the relevant textbook chapter, then read one primary research paper or official policy report. Record the research question, data, method, principal finding and limitations.
