COURSE FRAMEWORK

Syllabus

A graduate-level introduction to the mathematical foundations, statistical principles and computational practice of machine learning. The course develops supervised and unsupervised learning methods, regularization, model assessment, ensemble algorithms and neural networks, with reproducible applications in Python and R.

Learning outcomes

  1. Translate applied questions into supervised or unsupervised learning tasks and define suitable targets and loss functions.
  2. Derive and fit regularized linear and generalized linear prediction models.
  3. Compare classification and regression algorithms using defensible validation designs and performance metrics.
  4. Explain tree-based, kernel and neural-network methods and their computational trade-offs.
  5. Use resampling, tuning and interpretation tools to assess generalization and communicate model limitations.
  6. Build reproducible machine-learning workflows using Python or R.

Prerequisites and tools

Linear algebra, calculus, probability and introductory statistics. Software and resources: Python, R.

Teaching format

Lectures, guided examples, discussion, independent reading and applied assignments. Each session includes a conceptual framework and an exercise connecting the material to a practical problem.

Assessment

Suggested weighting: participation and preparation 10%; problem sets 25%; applied assignments 25%; midterm 15%; final project or examination 25%.

Academic practice

Students should cite data and sources, document computational workflows, distinguish evidence from interpretation, and disclose limitations.
